# Прогнозирование оттока клиентов «ТелеДом»

Проект машинного обучения для выявления клиентов с высоким риском ухода. Данные из четырёх источников объединены по `customerID`, исследованы и подготовлены для обучения моделей классификации.

## Результат

Лучшая модель — **Gradient Boosting**.

| Метрика | Значение |
|---|---:|
| ROC AUC, кросс-валидация | 0.866 |
| ROC AUC, тестовая выборка | 0.859 |
| Accuracy | 0.886 |
| Precision для оттока | 0.772 |
| Recall для оттока | 0.382 |
| F1 для оттока | 0.511 |

Тестовая выборка использована один раз после выбора модели по пятифолдовой стратифицированной кросс-валидации. При стандартном пороге 0.5 модель точнее отмечает клиентов с высоким риском, но выявляет не весь отток; рабочий порог следует выбирать с учётом стоимости контакта и потери клиента.

## Что сделано

- проверены пропуски, дубликаты и уникальность идентификаторов;
- корректно создан целевой признак до преобразования дат;
- объединены договоры, персональные данные, интернет- и телефонные услуги;
- рассчитана длительность обслуживания на дату среза 2020-02-01;
- выполнен EDA по балансу классов, платежам, сроку обслуживания и категориям;
- преобразования заключены в `Pipeline`, чтобы исключить утечку данных;
- сравнены Logistic Regression, Random Forest и Gradient Boosting;
- построены ROC-кривая, матрица ошибок и график важности признаков.

## Основные наблюдения

- В выборке 7 043 клиента, доля зафиксированного оттока — 15.6%.
- В этом срезе более высокая наблюдаемая доля оттока встречается у клиентов с долгосрочными договорами, автоматической оплатой и оптоволоконным интернетом.
- Наиболее значимый признак итоговой модели — длительность обслуживания; также важны тип договора и денежные показатели.
- Наблюдаемые связи описательные и не доказывают причинность.
